# Visual Lab

Página web de Visual Lab, agencia de edición de video y diseño para marcas personales.

- `index.html`: la página.
- `media/`: videos comprimidos para web. `img/`: portadas, logo e íconos.
- Para cambiar un texto o precio, edita `index.html` y guarda: GitHub Pages publica el cambio en uno o dos minutos.
